Curriculum

Comprehensive 5-Month Modules

Module 1 · Weeks 1–4 Python Foundation

Python Programming & Data Wrangling

Data structures, functional programming, OOP in Python, NumPy multi-dimensional arrays, Pandas indexing, slicing, aggregation, and handling dirty missing values.

Module 2 · Weeks 5–8 Math & Stats

Applied Statistics & Exploratory Data Analysis

Descriptive & inferential statistics, probability distributions (Normal, Poisson), central limit theorem, A/B testing, hypothesis tests (Z-test, T-test, ANOVA, Chi-square), Seaborn & Matplotlib visual storytelling.

Module 3 · Weeks 9–14 Algorithms

Supervised & Unsupervised Machine Learning

Scikit-learn modeling, Linear/Ridge/Lasso Regression, Logistic Classification, Decision Trees, Ensembles (Random Forests, Gradient Boosting, LightGBM), K-Means, Hierarchical Clustering, and PCA.

Module 4 · Weeks 15–20 Production

Model Deployment & Interactive Dashboards

Building web apps with Streamlit, model serialization (Pickle / Joblib), SQL queries for data science, deploying to AWS / Render, and writing comprehensive technical reports.
