Detailed Curriculum

Module 1 · Weeks 1–4 Fundamentals

Python for AI, Linear Algebra & Probability

Vector spaces, matrix decomposition (SVD), gradients, derivatives, NumPy vectorization, Pandas data cleaning, and statistical hypothesis testing.

Module 2 · Weeks 5–10 Core ML

Classical Machine Learning Algorithms

Linear & Logistic Regression, Decision Trees, Random Forests, XGBoost, Support Vector Machines (SVM), K-Means Clustering, and PCA dimensionality reduction.

Module 3 · Weeks 11–16 Deep Learning

Deep Neural Networks & PyTorch Architecture

Feedforward NNs, Backpropagation, Activation functions (ReLU, GELU), Optimizers (AdamW), Loss functions, and Convolutional Neural Networks (CNNs) for vision.

Module 4 · Weeks 17–20 NLP & LLMs

Natural Language Processing & Generative AI

Word Embeddings, Recurrent Networks, Attention Mechanism, Transformer Architecture, BERT, GPT Fine-tuning, RAG (Retrieval Augmented Generation), and Vector DBs.

Module 5 · Weeks 21–24 Deployment

MLOps & Production Model Serving

Dockerizing models, building inference APIs with FastAPI, CI/CD with GitHub Actions, model monitoring, MLflow tracking, and deployment on AWS SageMaker / EC2.
